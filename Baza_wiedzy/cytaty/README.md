# REJESTR CYTATÓW UŻYTKOWNIKA 1:1

Ten folder zawiera nienaruszalne, surowe wypowiedzi użytkownika ze wszystkich sesji roboczych, wraz z ich kontekstem.

### Zasada działania
* Każda wypowiedź użytkownika jest rejestrowana 1:1, bez upiększania, cenzury i interpretacji.
* Kontekst wyjaśnia, na co dana wypowiedź była reakcją.
* Jest to pierwotne źródło prawdy dla wszelkich syntez, reguł i specyfikacji w projekcie.

### Zawartość folderu
1. **`wywiad_pierwotny_wpisy_1_36.md`** — Kompletny, pierwotny wywiad projektowy (Wpisy 1–36) z początku projektu.
2. **`baza_cytatow_z_kontekstem.md`** — Pełne archiwum cytatów, definicji słownikowych i wypowiedzi tematycznych z okresu 2026-09-13 do 2026-09-20 (ponad 1500 linijek przeniesionych z dawnego `o_tobie.md`).
3. **`2026-09-20_dzisiejsza_sesja.md`** — Zapis wypowiedzi 1:1 z dzisiejszej sesji (2026-09-20).
