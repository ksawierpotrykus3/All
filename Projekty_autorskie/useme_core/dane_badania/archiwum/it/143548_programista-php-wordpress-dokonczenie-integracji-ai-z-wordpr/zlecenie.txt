Opis
Szukam doświadczonego programisty WordPress/PHP, który pomoże dokończyć integrację autorskiej wtyczki do autoblogowania opartej o AI (RAG/GEO) z WordPress. Projekt jest już w zaawansowanym stadium – mamy działające demo produkcyjne, ale wymaga ono dopracowania i usunięcia kilku błędów.

https://signalneural.com/wordpress.php

https://signalneural.com/wordpress-demo.php

Co już działa:

· Panel zarządzania wtyczką z widokiem dziennego limitu artykułów (12/90)

· Dodawanie i zarządzanie witrynami WordPress (Active Sites 1/3)

· Generowanie artykułów z ocenami SEO, GEO i Content (np. 91/88/95)

· Publikacja artykułów na podpiętych stronach WordPress

· System API z kluczem Global Secret (64-znakowy)

· Szablon wtyczki z interfejsem użytkownika

Co wymaga dokończenia / poprawy:

· Pełna, stabilna integracja z REST API WordPress (obecnie działa częściowo)

· Automatyczne generowanie i osadzanie JSON-LD Schema.org w artykułach

· Poprawa komunikacji między panelem SignalNeural a wtyczką Bridge

· Debugowanie błędów przy synchronizacji statusu artykułów (draft/published)

· Optymalizacja procesu autopilota (harmonogram, tematy)

· Ewentualnie: rozbudowa o obsługę wielu stron i zaawansowane raportowanie

Wymagania:

· Bardzo dobra znajomość PHP, WordPress (hooks, REST API, cron)

· Doświadczenie z integracjami API (REST, autoryzacja kluczami)

· Znajomość JSON-LD i podstaw SEO mile widziana

· Umiejętność czytania i modyfikowania istniejącego kodu (nie piszemy od zera)

Proszę w zgłoszeniu o:

· Krótkie info o doświadczeniu z WordPress API

· Szacowany czas realizacji

· Stawkę / wycenę
