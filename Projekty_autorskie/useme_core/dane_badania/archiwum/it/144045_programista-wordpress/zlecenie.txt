Programista Wordpress
=====================
URL: https://useme.com/pl/jobs/programista-wordpress,144045/

Zleceniodawca
kodiwo

Opis
Poszukuję programisty WordPress z dobrą znajomością PHP i minimum 3-letnim doświadczeniem komercyjnym.

Praca w niepełnym wymiarze godzin (part-time), z perspektywą współpracy przez kilka miesięcy.

Projekt obejmuje modernizację istniejącego serwisu internetowego oraz przygotowanie go do skalowania na kolejne rynki. Zakres prac to rozwój i refaktoryzacja, tworzenie dedykowanych rozwiązań oraz rozwiązywanie problemów technicznych.

Wymagania:

- Minimum 3 lata doświadczenia w pracy z WordPressem.

- Znajomość SOLID.

- Dobra znajomość PHP.

- Bardzo dobra znajomość API WordPressa.

- Znajomość GIT Flow.

- Otwartość na nowoczesne rozwiązania i umiejętność ich praktycznego wykorzystania.

- Umiejętność tworzenia i modyfikowania motywów oraz wtyczek.

- Znajomość HTML, CSS i JavaScript.

- Samodzielność, terminowość i dobra komunikacja.
