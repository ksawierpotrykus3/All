Wymagane funkcje:
We need a full-stack MERN developer to build a SaaS platform similar to PayKickstart.

The platform should include:

- User authentication and account management
- Multi-user roles and permissions
- SaaS dashboard with analytics and reporting
- Product/service management
- Customer management (CRM-style features)
- Subscription management
- One-time and recurring payment support
- Stripe/payment gateway integration
- Checkout flow and customizable checkout pages
- Order and transaction management
- Invoice and billing history
- API integration capabilities
- Admin dashboard for managing users, products, payments, and system settings
- Email notifications and automated workflows
- Responsive UI for desktop and mobile

Technical requirements:
- React / Next.js frontend
- Node.js + Express backend
- MongoDB database
- REST API architecture
- Secure authentication and authorization
- Clean, scalable, production-ready code

Preferowane rozwiązanie:
We prefer a custom MERN stack solution built from scratch rather than using WordPress, Shopify, or other ready-made platforms.

The ideal solution should be:

- Modern SaaS architecture
- Scalable and maintainable
- Component-based React frontend
- Well-structured Node.js backend
- Secure API design
- Cloud-ready deployment
- Easy to extend with future features

The developer should provide clean code, documentation, and collaborate with our team during the development process.

Umiejętności:
