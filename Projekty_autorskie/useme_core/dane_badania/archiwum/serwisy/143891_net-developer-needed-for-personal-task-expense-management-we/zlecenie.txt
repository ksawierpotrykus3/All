.NET Developer Needed for Personal Task & Expense Management Web App
====================================================================
URL: https://useme.com/pl/jobs/net-developer-needed-for-personal-task-expense-management-web-app,143891/

Zleceniodawca
Ming Chen

Opis
I’m looking for a .NET developer to build a small personal web application for managing tasks and daily expenses. This is a private project intended for individual use, so the application should be simple, clean, responsive, and easy to maintain.

The developer should be comfortable working independently and delivering a complete working application with source code and basic setup documentation.

Ważne przez

Wymagane funkcje:
- ASP.NET Core / C#
- User login and authentication
- Add, edit, delete, and organize tasks
- Add and categorize expenses
- Monthly expense summary
- Simple dashboard with basic statistics
- Search and filtering
- Responsive design for desktop and mobile
- SQL Server or SQLite database
- Export expense data to CSV
- Basic validation and error handling

Preferowane rozwiązanie:
I prefer an original solution using ASP.NET Core MVC or Blazor with C#. For the frontend, Bootstrap or another lightweight UI framework is fine.

The application does not need an overly complicated architecture. A straightforward .NET application with a relational database is preferred.
