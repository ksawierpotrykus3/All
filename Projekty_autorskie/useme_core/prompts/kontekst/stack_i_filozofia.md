# Stack i Filozofia (Wiedza dla Selekcjonera)

## Stack i specjalizacje
- Mobile (PRIORYTET - uwielbiamy aplikacje mobilne): Kotlin, Android SDK, Flutter, mobile dev
- Backend, Enterprise & Języki: .NET, C#, Python, Node.js / TypeScript, PHP
- Automatyzacje: Make, n8n, Zapier, Airtable, skrypty integracyjne
- AI: agenci AI, OpenAI API, moduły AI, RAG, klasyfikatory intencji, OCR + LLM
- Web, CMS & SaaS: aplikacje webowe, serwisy SaaS, systemy POS, Moodle, WordPress (ACF PRO, motywy), dedykowane panele
- Integracje i IoT: integracje API (Notion, CloudTalk, CRM), systemy rezerwacji (Booking), inteligentne zamki (smart locki), webhooki
- E-commerce: WooCommerce, Shopify, PrestaShop, integracje API z BaseLinkerem

## Filozofia działania
- Sprzedajemy wynik, wiedzę i partnerstwo.
- Bierzemy KAŻDE zlecenie programistyczne i automatyzacyjne (w tym Mobile, Kotlin, .NET, SaaS, POS, Moodle, systemy z wieloma integracjami).
- Gdy klient ma niesprecyzowane zlecenie ("brak konkretów" / "chcę AI ale nie wiem jakie"): BIERZEMY! Od tego jest krótka oferta z informacją, że przeprowadzimy gościa przez wszystko od A do Z i doprecyzujemy szczegóły na priv.
- Gdy projekt jest duży (SaaS, POS, złożone rezerwacje): BIERZEMY! Oferujemy realizację fazową lub start od funkcjonalnego MVP.
- ODRZUCAMY TYLKO:
  1. Czysty marketing i reklamy (np. Google Ads, Facebook Ads, SEO copywriterskie),
  2. Prace asystenckie/biurowe (np. manualne wklepywanie produktów do sklepu / admin BaseLinker bez API),
  3. Szkolenia i bycie wykładowcą (np. trener MariaDB),
  4. Mechanikę przemysłową i obróbkę skrawaniem (np. maszyny CNC Punch).
