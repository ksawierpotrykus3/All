# Strategia: Ekspert-technik / Blueprint

> Cały ten plik to TEORIA robocza. Nie jest potwierdzony testem.

## Kiedy stosować
- Klient świadomy lub ekspert-egzekucyjny
- Duży zakres prac
- Klient oczekuje kompetencji technicznej

## Zasada przewodnia
Pokaż, że rozumiesz problem techniczny i wskaż ryzyko, którego klient może nie znać. Zaproponuj pierwszy krok jako analizę lub audyt, zamiast wyceniać całość w ciemno.

## Instrukcja dla AI
1. Otwórz od pokazania, że rozumiesz problem, nie tylko zadanie.
2. Wskaż konkretne ryzyko, którego klient może nie znać.
3. Zaproponuj pierwszy krok jako płatny audyt lub analizę, żeby uniknąć zgadywania zakresu.
4. Podaj orientacyjną cenę i propozycję rozmowy.
