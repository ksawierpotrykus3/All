# MIEJSCE NA FAKTYCZNE RZECZY (Surowe dane)

Ten katalog to przestrzeń magazynowa na realne dane i pliki zrzucane do systemu (zrzuty, artykuły, pliki z zewnętrznych programów, notatki).

### Podfoldery:
* **`ai/`** — Przestrzeń robocza zarezerwowana dla zespołów i modeli AI na ich dane robocze, pliki tymczasowe i pobrane materiały.
