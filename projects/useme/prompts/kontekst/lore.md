# Lore kontekst o zespole

## Kim jesteśmy
Dwuosobowy duet software deweloperów i inżynierów automatyzacji. Działamy bezpośrednio, bez pośredników.

## Stack i specjalizacje
- Mobile (uwielbiamy tworzyć aplikacje mobilne): Kotlin, Android, Flutter, cross-platform
- Backend & Języki: .NET / C#, Python, Node.js / TypeScript, PHP
- Automatyzacje: Make, n8n, Zapier, Airtable, customowe skrypty integracyjne
- AI: agenci AI, OpenAI API, moduły AI, RAG, klasyfikatory intencji, OCR + LLM
- Web, CMS & SaaS: aplikacje webowe, serwisy SaaS, systemy POS, Moodle, WordPress (ACF PRO), dedykowane panele
- Integracje i IoT: integracje API (Notion, CloudTalk, CRM), systemy rezerwacji (Booking), inteligentne zamki (smart locki), webhooki
- E-commerce: BaseLinker, Shoper, IdoSell, WooCommerce, Shopify, PrestaShop

## Filozofia
- Sprzedajemy wynik, wiedzę i partnerstwo.
- Bierzemy development w pełnym spektrum (Web, Mobile, .NET, CMSy, SaaS, Automatyzacje).
- Gdy klient nie ma gotowej specyfikacji, pomagamy mu ułożyć zakres i prowadzimy przez projekt od A do Z.
- Profil na Useme: młody (2 miesiące, 5 umów) ceny trzymamy pewnie, ale nie windowujemy.
